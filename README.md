## About 100days

100days is a home-screen widget for Android and iOS that counts down the final 100 days of 2026. No soft landing, no snooze — just the number of days left and a reason to move.

## Features

- [ ] Home-screen widget (Android + iOS) with a live days-remaining count
- [ ] Daily rotating motivational message
- [ ] In-app countdown screen with streak tracking
- [ ] Local daily reminder notification
- [ ] Turborepo monorepo: `apps/mobile` (Expo) + shared `packages/*`
